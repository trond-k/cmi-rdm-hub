# Examples

These examples show how the starter inventory can work across different project types. They are not templates to copy blindly. They show the level of detail that is usually enough for a working inventory.

For a publishable project-level example, see [Worked example: service access study](worked-example-composite-service-access.md). For a more complex internal stress-test, see [AHEAD](worked-example-ahead.md).

## Interview project

| Data object name | Short description | Data type or material | Source or method | Project context | Responsible role | Personal data and sensitivity | Legal, Sikt, or restriction note | Storage location | Access | Status | Retention or end state |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Recruitment and contact list | Names and contact details for possible interviewees | Recruitment records | Created by project team | Work package 1, country A | Qualitative RA | Direct identifiers; possibly sensitive role information | Covered by Sikt notification and information sheet | Restricted project storage | PI and qualitative RA only | Live | Delete when recruitment and follow-up are complete |
| Interview audio recordings | Audio files from semi-structured interviews | Interview recordings | Created by project team | Work package 1, country A | PI | Voice identifiers; politically sensitive context | Covered by Sikt notification and consent procedure | Restricted project storage | PI and approved transcription support only | Processing | Delete after transcript verification unless retention is justified |
| Pseudonymised interview transcripts | Transcripts with names and direct identifiers removed or replaced | Interview transcripts | Derived from interview audio recordings | Work package 1, country A | PI | Personal data may remain through context | Check contextual identifiability before sharing | Restricted project storage | Project analysis team | Live | Retain internally; assess restricted archiving at closure |
| Publication excerpts | Selected quotes reviewed for disclosure risk | Derived text excerpts | Derived from pseudonymised transcripts | Article 1 | PI and article authors | Low to medium; contextual risk depends on quote | Review against participant expectations and context | Article working folder | Article authors | Ready for review | Publish only after disclosure review |

| Raw survey export | Original export from survey platform, including timestamps and free-text answers | Survey data | Created by project survey | Baseline survey | Survey lead | Personal data possible; indirect identifiers; free-text risk | Covered by Sikt notification if personal data are present | Restricted project storage | Survey lead and data manager | Live | Retain until cleaned dataset is verified; review for deletion |
| Cleaned survey dataset | Cleaned data prepared for analysis | Survey data | Derived from raw survey export | Baseline survey | Data manager | Reduced personal data; re-identification risk to be assessed | Check against Sikt and consent before wider access | Project analysis folder | Project analysis team | Processing | Retain internally during analysis |
| De-identified analytical dataset | Dataset with identifiers removed or generalised | Analytical dataset | Derived from cleaned survey dataset | Publication and replication | Data manager | Intended non-personal or low risk; verify before sharing | Disclosure review required before deposit | Archive preparation folder | Data manager and PI | Ready for review | Archive openly or restricted depending on risk review |
| Survey codebook | Variable names, labels, values, missing codes, and derived variables | Documentation | Created by project team | Baseline survey | Data manager | No personal data | Not applicable | Documentation folder | Project team | Live | Preserve with dataset or replication package |

| Derived indicators | Aggregated or transformed indicators created from extract | Derived dataset | Derived from original administrative extract | Work package 3 analysis | Data manager | Lower risk; disclosure review needed | Publication may be limited by agreement | Project analysis folder | Project analysis team | Processing | Share only if agreement and disclosure review allow |
| Restriction note | Summary of contractual, ethical, and publication limits | Documentation | Created by project team | Work package 3 | PI | No personal data unless notes identify people | Based on data sharing agreement | Documentation folder | Project team | Live | Preserve with project records and outputs |
