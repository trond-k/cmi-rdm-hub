# CMI data inventory approach: proposed sitemap

This sitemap is deliberately smaller than the OpenAI draft. The Hub should make the data inventory feel like a useful working document, not a system researchers have to master before they can begin.

## 1. Orientation

- What is a data inventory?
- What is a data object?
- Choosing the right level of detail

Purpose: introduce the approach in plain language and show why the inventory is useful for CMI projects.

## 2. The starter inventory

- The CMI starter inventory
- Starter template
- How to update the inventory over time

Purpose: give researchers the practical minimum they can use immediately.

## 3. Method examples

- Worked example: service access study
- Interview and focus group projects
- Survey projects
- Fieldnotes and research diaries
- Administrative or partner-provided data
- Document-based research
- Social media and digital trace data
- Code, scripts, and analytical files

Purpose: show how the same starter inventory works across common CMI research situations.

## 4. Decision guidance

- Personal data and contextual identifiability
- Storage, access, and transfer
- Documentation and README files
- Sharing, archiving, retention, and deletion
- Partner responsibilities and restrictions
- Project closure

Purpose: connect inventory entries to practical decisions. This section should not duplicate all topical Hub pages. It should point to them and explain what the inventory needs to record.

## 5. Optional field groups

- GDPR and personal data follow-up
- Ethics and contextual risk follow-up
- Partner, provider, and agreement follow-up
- Documentation follow-up
- Sharing and archiving follow-up
- Closure and deletion follow-up

Purpose: make the larger field model available without putting it in the default template.

## 6. Advanced reference

- Advanced field reference
- Full schema mapping
- DMP rendering notes
- Public manifest vs private inventory
- Internal stress-tests, including AHEAD

Purpose: preserve the technical approach for advisers, templates, and future tooling.

## Recommended reading path

Most researchers:

1. What is a data inventory?
2. What is a data object?
3. The CMI starter inventory
4. One method example relevant to their project

Research advisers and project managers:

1. All orientation pages
2. The CMI starter inventory
3. When to add more detail
4. Decision guidance
5. Advanced reference when needed
