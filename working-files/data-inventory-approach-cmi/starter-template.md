## Status values

Recommended values:

- Planned
- Live
- Processing
- Ready for review
- Archived
- Deleted
- Retained
- To be reviewed

## Sensitivity prompts

Use short, practical wording. Examples:

- No personal data
- Personal data
- Direct identifiers
- Voice identifiers
- Special category data
- Politically sensitive
- Contextually identifiable
- Confidential partner data
- Public material
- Unknown, to be reviewed

## Retention or end-state prompts

Use action-oriented wording. Examples:

- Delete after transcript verification
- Delete at project closure
- Retain internally for 5 years after project closure
- Retain internally while publication is under review
- Archive with restricted access
- Archive openly after disclosure review
- Share derived or aggregate version only
- Transfer to partner under agreement
- Review before project closure
