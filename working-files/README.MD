This folder is a pool of drafts, notes, and reference material. It feeds into
the refined content in `docs/`.

The folder structure mirrors the navigation sections defined in `zensical.toml`,
so working material maps directly to its published destination.

## Structure

| Folder | Mirrors | Contents |
|--------|---------|----------|
| `foundations/` | Foundations nav section | Principles, CMI context, data sharing, lifecycle concepts |
| `before-the-project/` | Before the project | Frame, Fund, Plan stage material |
| `during-the-project/` | During the project | Collect, Store, Process, Analyse stage material |
| `after-the-project/` | After the project | Publish, Preserve, Discover, Access, Share & Reuse, closure |
| `topics/` | Topics nav section | Legal, ethics, security, reproducibility |
| `tools-and-templates/` | Tools and templates | Data inventory, DMP, Sikt form, AI usage |

Three folders sit outside the mirror structure:

| Folder | Purpose |
|--------|---------|
| `_archive/` | Superseded early drafts and retired widgets |
| `_meta/` | Blueprints, prompts, and internal operational recommendations |
| `examples/` | Fictional example documents (e.g. an exemplar DMP; real project DMPs were removed from the public repo) |
| `data-inventory-approach-cmi/` | Draft materials for the CMI data inventory approach |

## How to use

Drafts here are starting points, not constraints. When reworking content for
`docs/`, improvements to structure, scope, and tone are expected. Each draft
is supplemented by fresh research and checked against the style guide and
review checklist before it moves into `docs/`.
