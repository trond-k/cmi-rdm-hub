# Data inventory template

*Copy the template below into your project documentation and fill in the fields. It works as a standalone inventory or as Section 3 of CMI's institutional DMP template. For guidance on what each field means and worked examples, see [The data inventory](data-inventory.md).*

!!! tip "How to use this template"
    Select from the summary table heading downwards, copy, and paste into Word, Google Docs, or your preferred editor. Markdown formatting (headings, tables, bold, lists) transfers as rich text in most applications. Replace bracketed placeholders with your project's details and duplicate the record entry as many times as needed.

**Type**: qualitative, quantitative, mixed, or secondary.
**Sensitivity**: Green (open), Yellow (internal), Red (restricted), or Black (strictly restricted).
**Sharing pathway**: open, registered, controlled, restricted, or no external sharing.
**Status**: planned, in collection, complete, archived, or deleted.

## Data records

One entry per data record (or per group of similar records). Target 15–20 lines per entry. State what will be done, not why; rationale belongs in the DMP's cross-cutting policies section. If you have six or more similar records, describe the set in the summary table and provide a full entry only for those that differ materially.
